## 1. Điểm mới trong bản phát hành `v1.0.0`

- **Trọn vẹn vòng game 4 phase (`Contract v1.0 → v1.3`):**
  - **Buổi sáng (`gather`):** Bơi `[x, d]` trên sông Chín Khúc (`100m × 30m`), hái `Bông điên điển` / `Bông súng` / `Kèo nèo` (`N1..N6`), bắt `Cá linh` / `Cá lóc` / `Cá kèo` (8→12 đàn cá bơi/phản xạ mép/sinh thêm), quản lý oxy & 3 Máu, tránh **Cá Sấu Năm Chèo (`M1`, `M2`)**, độ tươi giỏ giảm `0.5/s` (`spoiled` ở `< 30`).
  - **Buổi tối (`quan`) & Tiệm (`shop`):** Phục vụ tối đa 4 bàn (`T1..T4`), 2 bếp (`B1..B2`), 6 món đặc sản theo `day_plan` từng Ngày; kho cá thể giảm `0.25/s`, tự động nhả & giữ lại theo `(order_tick, id bàn)` khi nguyên liệu vừa ươn, giá món chốt `floor(price × avg_fresh / 100)`; cuối ngày nâng cấp **Bình oxy** / **Áo phao** trong `Shop`.
- **Mới ở Phase 4 (`v1.3`):**
  - **Cảnh báo trực quan không phụ thuộc màu:** chữ + biểu tượng + viền nét đứt xếp chồng cho **Thủy quái gần**, **Oxy sắp hết / Hết oxy** và **Khách sắp giận**.
  - **Chế độ tương phản cao (`High-Contrast`):** bật/tắt bằng phím `H`, nút HUD góc phải trên, nút trong Menu/Pause hoặc `?hc=1` (lưu `localStorage`).
  - **Benchmark có render `1280×720` (`chonoi.bench`):** đạt **`73.8149` FPS trung bình**, **`33.9265` FPS 1% low**, **`1575.97` ms tải cảnh đầu tiên** (`30.0075 s`, `2215` khung hình, seed `42` — xem [`docs/proof/phase-4/bench.json`](../proof/phase-4/bench.json)).
  - **Soak headless `10 Ngày` (`chonoi.soak`):** bot tất định chơi liền mạch D1–D10 (lặp kế hoạch D1–D5 ở Ngày 6–10) đạt `days_completed: 10`, `crashes: 0`, tổng thu `2688k`, uy tín `5.0`, điểm `3188`, lặp lại 2 lần khớp `100%` (xem [`docs/proof/phase-4/soak.json`](../proof/phase-4/soak.json)).
  - **Bộ test tự động:** **`70 / 70` tests PASS** (gồm hồi quy P1–P3 và toàn bộ kiểm thử v1.3 ở P4).

## 2. Cách chạy nhanh

### Từ clone sạch (tối đa 3 lệnh, macOS / Linux)
```bash
git clone https://github.com/tcaopham216-gif/K5-L3B-LAB-Day12-AI-SDLC-Uno.git
cd K5-L3B-LAB-Day12-AI-SDLC-Uno
python3 -m chonoi.live --mode day
```
Sau khi server báo `http://127.0.0.1:8000/`, mở link trên trình duyệt. *(Trên Windows chạy `python -m chonoi.live --mode day`.)*

### Từ gói đóng gói Release (`quan-an-cho-noi-v1.0.0.zip` / `.tar.gz`)
- **macOS / Linux:**
  ```bash
  tar -xzf quan-an-cho-noi-v1.0.0.tar.gz && cd quan-an-cho-noi-v1.0.0
  ./run.sh
  ```
- **Windows:** Giải nén `quan-an-cho-noi-v1.0.0.zip`, mở thư mục `quan-an-cho-noi-v1.0.0` và chạy `run.bat` (hoặc `python -m chonoi.live --mode day`).

### Lệnh kiểm tra, benchmark & soak
```bash
PYTHONPATH=tests:. python3 -m unittest discover -s tests -v
python3 -m chonoi.bench --seed 42 --duration 30 --out bench.json
python3 -m chonoi.soak --seed 7 --days 10 --out soak.json
```

## 3. Yêu cầu môi trường & Giới hạn đã biết

- **Yêu cầu:** Python `3.10+` (chỉ dùng thư viện chuẩn, không cần cài thêm package); trình duyệt hiện đại cho chế độ chơi trực tiếp (`chonoi.live`); Tkinter (đi kèm bản cài Python desktop) cho benchmark GUI `1280×720`.
- **Giới hạn đã biết:**
  - Nhóm có 1 thành viên (`team_size: 1`) nên chỉ triển khai trọn vẹn phần **Lõi** và đặt `"extensions": []` (không bật `leaderboard` / `sfx_subtitles` hay các phần Mở rộng tùy chọn).
  - Trong môi trường Linux headless/CI không có display (`$DISPLAY`), `chonoi.bench` tự động chuyển sang software framebuffer `1280×720` thay vì mở cửa sổ Tkinter (chỉ định `--renderer tk` để ép dùng Tkinter).
  - Đồ họa và cảnh báo thuần code qua HTML5 Canvas (không có âm thanh nền ngoài trình duyệt).
